ABUZAR.DEV — SETUP

1. Download and extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or install the Live Server extension and select "Open with Live Server".
4. Replace hello@example.com in index.html with your email address.
5. Update the sample project descriptions and links as you complete your own projects.

Responsive layouts are included for desktop/laptop, tablet, and mobile screens. The navigation menu becomes a collapsible menu on small screens.

Note: Project cards are visual portfolio concepts, not deployed apps. Social links are placeholders.
